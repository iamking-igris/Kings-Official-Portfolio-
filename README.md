## Contact form

Uses [Web3Forms](https://web3forms.com) — no custom backend.

1. Create a form key pointed at `michaelkm555@gmail.com`
2. Set `NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY` in `.env.local`
3. Redeploy / restart

Without the key, the form validates and shows a clear configuration message (no fake success).
